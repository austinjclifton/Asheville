To run locally, start the backend by running

- cd backend
- npm run dev

and then start the frontend by running

- cd frontend
- npm run dev

To see the Mermaid diagrams:

- Download the Mermaid and the Mermaid Preview extensions
- Open the Mermaid file
- Right-click inside of it, and select
  `MermaidChart: Preview Diagram`

To see the Swagger.io API documentaion:

- Run the backend (see above)
- Go to this link:
  `http://localhost:4000/api-docs/`
